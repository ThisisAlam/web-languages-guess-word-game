# 🎮 Web Languages: Endgame

A fun and interactive word guessing game built with **React.js** where every wrong guess eliminates a web language from existence.
Can you save the programming world before **Assembly** takes over? 💀

---

## 🚀 Live Gameplay Concept

In this game:

* Players guess hidden words letter by letter
* Every wrong guess kills a web language
* Languages get crossed out with skull overlays ☠️
* Dynamic farewell messages appear after each eliminated language
* Win the game to save the web 🌐
* Lose the game and Assembly destroys everything 😭

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/ThisisAlam/web-languages-guess-word-game.git
```

Go to the project folder:

```bash
cd web-languages-guess-word-game
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
